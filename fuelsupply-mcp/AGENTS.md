# FuelSupply durable rules
Work locally; never deploy, submit, push, publish, enable tracing, or modify global Codex settings without explicit authorization. Preserve template attribution and existing work.
Only verified, metadata-backed EIA mappings may be enabled. Never guess series or substitute products. Synthetic fixtures stay in tests and never appear as market data.
Use Python >=3.11, uv lockfile, FastMCP, Pydantic, one tool per file. Keep analytics deterministic and credentials server-side. Logs go to stderr; do not log upstream URLs, bodies or errors.
Run unit/API tests and a real stdio MCP session after changes. Record actual counts and limitations in PLANS.md and evaluation documents. Public-data market analysis cannot establish purchasable quantities, spare capacity or forecasts.
